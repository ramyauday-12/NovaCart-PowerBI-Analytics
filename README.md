# NovaCart | E-Commerce Sales & Profitability Analytics

An interactive **E-Commerce Sales & Profitability Analytics Dashboard** built using Microsoft Power BI to analyse business performance, identify trends, and support data-driven decision-making.

---

## 📊 Project Overview

NovaCart is an end-to-end Business Intelligence project focused on analysing e-commerce sales data from **January 2024 to December 2025**.

This project transforms raw business data into interactive visual reports, enabling users to explore sales performance, profitability, product trends, customer behaviour, geographical performance, promotions, and returns.

## 🎯 Project Objectives

- Analyse overall sales and profitability performance.
- Identify sales trends across different time periods.
- Evaluate product and category performance.
- Understand customer purchasing behaviour.
- Explore geographical sales distribution.
- Analyse promotional performance and product returns.
- Support business decisions through interactive dashboards.

## 🛠️ Tools & Technologies

| Technology | Purpose |
|---|---|
| Microsoft Power BI | Dashboard development and data visualisation |
| Power Query | Data cleaning and transformation |
| DAX | Measures and calculated metrics |
| Data Modelling | Relationships and dimensional modelling |
| Microsoft Excel | Dataset preparation and data handling |

## 🗂️ Data Model

The project uses an analytical data model consisting of the following tables:

| Table | Description |
|---|---|
| FactSales | Sales transaction data |
| FactReturns | Product return information |
| DimDate | Date and calendar information |
| DimProduct | Product details |
| DimCustomer | Customer information |
| DimGeography | Geographical information |
| DimPromotion | Promotion details |
| DimChannel | Sales channel information |

## 📈 Dashboard Pages

The report contains four interactive analytical pages:

1. **Sales Performance** – Explore overall sales and profitability trends.
2. **Product Analysis** – Analyse product and category performance.
3. **Customer & Geography Analysis** – Understand customer and geographical sales patterns.
4. **Promotions & Returns Analysis** – Examine promotional performance and product returns.

## 🔍 Key Analytical Capabilities

- Interactive filtering and drill-down analysis.
- Time-based sales trend analysis.
- Product and category comparisons.
- Customer and geographical segmentation.
- Promotion and return analysis.
- Business performance monitoring through visual KPIs.

## 📁 Project Files

## 🚀 How to Explore the Project

1. Clone or download this repository.
2. Open the `.pbip` project file using Microsoft Power BI Desktop.
3. Refresh the data if required.
4. Explore the report pages and interact with the available filters and visuals.

> **Note:** Microsoft Power BI Desktop is required to open and interact with the report.
